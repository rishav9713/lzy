# LZY brand assets

| File | What it is | Size |
|---|---|---|
| `lzy-banner.png` | Wide header banner, used at the top of the README | 2172 x 724 |
| `lzy-logo.png` | The mark. Sleeping sloth in a hexagon. Use this for the repository avatar, social cards and favicons | 585 x 585 |
| `lzy-mascot.png` | The mascot. Same sloth, sunglasses and hoodie. For community use: stickers, talk slides, anywhere a lighter touch fits | 585 x 585 |

All three have transparent backgrounds and are designed to sit on a dark
background.

`lzy-logo.png` is the one to reach for when something needs to look official,
and `lzy-mascot.png` when it does not. If you only pick one, pick the mark.

## The two lines

LZY uses two lines, on purpose:

- **Complex Logic. Simple Code.** is the tagline. It states what the language
  is for, and it is what SPEC.md, the documentation and the release notes
  use.
- **Code Less. Do More.** is the line on the artwork. It is the shorter,
  friendlier version for a banner, a social post or a talk slide.

They are not interchangeable. "Code Less" is a promise about typing, and
LZY's design philosophy explicitly rejects optimising for fewer characters
(see the design philosophy section of the README). The tagline is the one
that survives contact with that argument, so it is the one the specification
uses.

## Using them

Please do not restyle the mark, change its colours, or use it to suggest that
something is an official LZY project when it is not. Everything else is fine.

The assets are covered by the repository's Apache-2.0 licence.
