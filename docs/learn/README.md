# Learn LZY

A course that starts at "I have never written a program" and ends at "I can
build something".

Each level is short, ends with something that runs, and gives you a job to do
before the next one. Nothing is explained before you need it.

| Level | What you will be able to do | Status |
|---|---|---|
| [1](01-first-program.md) | Write and run your first program | Ready |
| [2](02-variables.md) | Keep things, and ask for them | Ready |
| [3](03-decisions.md) | Make your program choose | Ready |
| [4](04-loops.md) | Do something many times | Ready |
| [5](05-functions.md) | Name a piece of work and reuse it | Ready |
| 6 | Lists and maps | Not written yet |
| 7 | Algorithms | Not written yet |
| 8 | Building an application | Not written yet |
| 9 | Advanced LZY | Not written yet |

Levels 6 to 9 are outstanding, and are a good place to contribute — see
[CONTRIBUTING.md](../../CONTRIBUTING.md).

## Before you start

Install LZY (see the [README](../../README.md#installing)) and check it
works:

```bash
lzy --version
```

You will also want somewhere to write programs. Any text editor will do.

## How to use this course

**Type the programs out.** Do not copy and paste them. Typing is slower, and
that is the point: you notice things when you type them.

**Break things on purpose.** Every level ends by asking you to make a
mistake and read what LZY says. LZY's error messages are meant to teach, and
you will meet them anyway — better to meet them while you are looking.

**Do the job at the end** before you move on.
