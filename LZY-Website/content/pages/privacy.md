# Privacy

This website does not track you. It has no analytics, no advertising, no
cookies, and no accounts. This page lists everything it does store or send,
so you can check.

## What the site stores on your device

- **Your theme choice.** If you switch between light and dark, the choice is
  kept in your browser's local storage under the name `lzy-theme`, so the
  site remembers it next time. Nothing else is kept there.
- **GitHub star and fork counts**, for up to an hour, in session storage, so
  the site does not ask GitHub again on every page. They are deleted when you
  close the tab.

You can clear both at any time by clearing this site's data in your browser.

## What the site sends elsewhere

- **GitHub's API.** To show the repository's star count, your browser asks
  `api.github.com` for public information about the LZY repository. GitHub
  receives that request, including your IP address, as it would for any
  visitor to github.com. If the request fails or is blocked, the site works
  exactly the same without the numbers.

Nothing else is loaded from anywhere but this site: the fonts, images and
code are all served from here.

## Hosting

The site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for
security and operational reasons, as described in
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
The LZY project does not receive those logs.

## Links to other sites

Links to GitHub and elsewhere take you to sites with their own privacy
policies.

## Changes

This page is part of the website's source, so any change to it is public in
